## Quickstart

### 1. Remote state

Bootstrap a remote-state bucket once per tenant using
[`terraform-overlays-remotestate`](https://github.com/POps-Rox/terraform-overlays-remotestate)
and fill in `backend.tf` (or pass `-backend-config=` at init time).

### 2. Authenticate

The provider config declares one `azurerm` block per subscription. Either
log in with `az login` and a user that has `Owner` on all four subscriptions,
or set the OIDC / SPN environment variables (`ARM_CLIENT_ID`,
`ARM_CLIENT_SECRET`, `ARM_TENANT_ID`) and let each provider pick up the
correct subscription via its `subscription_id` argument.

### 3. Plan and apply

```bash
terraform init
terraform plan -out tfplan
terraform apply tfplan
```

## CI/CD

`.github/workflows/terraform.yml` invokes
`POps-Rox/terraform-gh-actions/terraform-plan@v1.0.0` on PRs and
`terraform-apply@v1.0.0` on push to `main`.

The workflow authenticates to Azure with **GitHub OIDC** (no long-lived
secrets). It expects the following **GitHub Actions variables** (not
secrets):

| Name | Scope | Notes |
| ---- | ----- | ----- |
| `AZURE_CLIENT_ID`        | org var, env override | Federated UAMI allowed to deploy in all four subscriptions |
| `AZURE_TENANT_ID`        | org var              | Tenant ID |
| `AZURE_SUBSCRIPTION_ID`  | org var, env override | Default subscription (overridden per `azurerm` provider alias) |
| `TF_STATE_RG`            | org var              | Remote-state RG |
| `TF_STATE_SA`            | org var              | Remote-state storage account |
| `TF_STATE_CONTAINER`     | org var              | Remote-state container |

See [`backstage/docs/azure-deploy-setup.md`](https://github.com/POps-Rox/backstage/blob/main/docs/azure-deploy-setup.md)
for the one-time UAMI + federated-credential + RBAC bootstrap. The landing-
zone scenario needs `Contributor` + `User Access Administrator` on **each**
of the hub, identity, operations, and workload subscriptions.

## Deploy to Azure

Once this repo is scaffolded:

1. Confirm org variables `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`,
   `AZURE_SUBSCRIPTION_ID`, `TF_STATE_RG`, `TF_STATE_SA`,
   `TF_STATE_CONTAINER` are set, and the UAMI has RBAC on all four
   target subscriptions
   (see [Azure deploy setup](https://github.com/POps-Rox/backstage/blob/main/docs/azure-deploy-setup.md)).
2. Open the repo on GitHub → **Actions** → **terraform** →
   **Run workflow** → pick `environment` and `action = apply`.
3. Or from the CLI:
   ```bash
   gh workflow run terraform.yml -f environment=dev -f action=apply
   ```

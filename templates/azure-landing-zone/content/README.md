## Quickstart

### 1. Remote state

Bootstrap a remote-state bucket once per tenant using
[`terraform-overlays-remotestate`](https://github.com/POps-Rox/terraform-overlays-remotestate)
and fill in `backend.tf` (or pass `-backend-config=` at init time).

### 2. Authenticate

The provider config declares one `azurerm` block per subscription. Either
log in with `az login` and a user that has `Owner` on all four subscriptions,
or set the OIDC / SPN environment variables (`ARM_CLIENT_ID`,
`ARM_CLIENT_SECRET`, `ARM_TENANT_ID`) and let each provider pick up the
correct subscription via its `subscription_id` argument.

### 3. Plan and apply

```bash
terraform init
terraform plan -out tfplan
terraform apply tfplan
```

## CI/CD

`.github/workflows/terraform.yml` invokes
`POps-Rox/terraform-gh-actions/terraform-plan@v1.0.0` on PRs and
`terraform-apply@v1.0.0` on push to `main`.

## Quickstart

### 1. Bootstrap remote state (once per subscription)

If your subscription does not already have a POps-Rox remote-state bucket, run
the [`terraform-overlays-remotestate`](https://github.com/POps-Rox/terraform-overlays-remotestate)
accelerator to create the state resource group, storage account, container,
and service principal.

Then fill in `backend.tf` with the produced names, **or** pass them at init
time:

```bash
terraform init \
  -backend-config="resource_group_name=<state-rg>" \
  -backend-config="storage_account_name=<state-sa>" \
  -backend-config="container_name=tfstate" \
  -backend-config="key=${{ values.name }}/${{ values.environment }}.tfstate"
```

### 2. Authenticate to Azure

```bash
az login
az account set --subscription <subscription-id>
```

### 3. Plan & apply

```bash
terraform init
terraform plan  -out tfplan
terraform apply tfplan
```

## CI/CD

The `.github/workflows/terraform.yml` workflow uses the
[`POps-Rox/terraform-gh-actions`](https://github.com/POps-Rox/terraform-gh-actions)
composite actions at `v1.0.0`:

* `terraform-plan@v1.0.0` runs on every pull request.
* `terraform-apply@v1.0.0` runs on push to `main`.

Configure the following repository secrets / variables:

| Name | Type | Purpose |
| ---- | ---- | ------- |
| `ARM_CLIENT_ID`        | secret | SPN client ID |
| `ARM_CLIENT_SECRET`    | secret | SPN client secret |
| `ARM_SUBSCRIPTION_ID`  | secret | Target subscription |
| `ARM_TENANT_ID`        | secret | Tenant ID |
| `TF_STATE_RG`          | var    | Remote-state resource group |
| `TF_STATE_SA`          | var    | Remote-state storage account |
| `TF_STATE_CONTAINER`   | var    | Remote-state container (e.g. `tfstate`) |
